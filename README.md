# 걸어볼까 (WalkAround)

The Living Map - 산책 & 트레일 탐색 앱

## 주요 기능

- **경로 탐색**: 추천 산책 경로 및 근처 트레일 검색
- **실시간 추적**: 산책 중 걸음수, 거리, 시간, 칼로리 실시간 표시
- **경로 상세**: 난이도, 설명, 커뮤니티 리뷰 확인
- **프로필**: 레벨 시스템, 통계, 최근 산책 기록
- **산책 기록**: 과거 산책 이력 관리

## 기술 스택

- Flutter 3.x + Material Design 3
- Provider (상태관리)
- Hive (로컬 저장소)
- fl_chart (차트)

## 시작하기

```bash
flutter pub get
flutter run
```
